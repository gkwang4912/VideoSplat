# DWPose model files

The program downloads these files automatically from `yzd-v/DWPose` on Hugging Face when DWPose is first used:

- `yolox_l.onnx`
- `dw-ll_ucoco_384.onnx`

Downloads use `.part` files for resume support. A model becomes active only after its size and SHA-256 pass validation. The model weights are not distributed in this repository.
