# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project follows [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [2.0.0] - Unreleased

### Added

- A deterministic 175-frame 360-degree skeleton-control stage with DWPose detection, silhouette fallback, fixed camera intrinsics, and known COLMAP poses.
- A ComfyUI reference-to-video workflow that combines the aligned source image with the skeleton-control video and exports separate generated color and mask videos.
- A known-pose dataset builder that decodes generated videos, creates binary masks, composes verified RGBA images, preserves COLMAP camera records, validates frame correspondence, and optionally exports a ZIP archive.
- A four-stage release pipeline ending in Brush 3D Gaussian Splatting training.
- A focused offline regression test for Stage 3 RGBA composition and the Stage 3 → 4 dataset handoff.
- V1 README snapshots, V2 architecture documentation, and a V1-to-V2 migration guide.

### Changed

- Camera poses are generated before video synthesis and reused unchanged instead of being estimated from generated frames.
- The current source layout keeps all four V2 stage directories under `src/`, matching the V1 repository convention without reusing V1 modules.
- Stage 3 writes each binary mask into the matching RGB image's alpha channel and retains separate masks for verification; Stage 4 reads the resulting RGBA dataset directly.
- Local Brush executable paths are configured with `VIDEOSPLAT_BRUSH_EXE` or PATH discovery instead of personal absolute paths.

### Removed

- The V1 five-stage source tree from the current `main` branch; it remains available through `v1.0.0`.
- The V1 XYZ Orbit Viewer, three-ring/twelve-path rendering stage, second video-refinement reconstruction stage, and V1 experimental test programs from the V2 working tree.
- Bundled local environments, model weights, runtime inputs, generated outputs, and training artifacts from version control.

### Breaking Changes

- V2 input, output, configuration, workflow, and stage boundaries are incompatible with V1.
- V2 does not estimate cameras with COLMAP; it requires the known 175-pose model generated by Stage 1.
- V1 commands and numbered stage names do not apply to V2. Follow the V2 README and migration guide.
- V2 runtime data contracts remain incompatible with V1 even though both versions place their main programs under `src/`.

## [1.0.0] - 2026-11-02

### Added

- Initial public release of the five-stage VideoSplat research pipeline.
- Repository layout with the five core pipeline stages under `src/`, the standalone Viewer at the root, and experimental test programs under `tests/`.
- Single-image orbit-video and mask generation through a ComfyUI workflow.
- Frame extraction, RGBA cleanup, COLMAP camera-pose estimation, and reconstruction quality validation.
- Initial 3D Gaussian Splatting training through the Brush CLI.
- Canonical-coordinate construction, six anchor views, three complete camera rings, and twelve fixed camera paths.
- Video-model refinement and export of second-stage COLMAP, Brush, and Nerfstudio-compatible datasets using known camera poses.
- Local XYZ Orbit Viewer for inspecting Gaussian PLY models, anchors, paths, and rendered views.
- Validation scripts and targeted tests for camera conversion, path orientation, dataset indexing, and the Viewer server.

### Known Limitations

- The project has no LICENSE file; reuse terms have not yet been defined.
- End-to-end automated tests and exact tested dependency versions are not defined.
- Stages 1 and 5 require a separately configured ComfyUI installation, compatible custom nodes, and local model weights.
- Stage 3 requires a compatible Brush CLI build with the flags used by this project.
- Stage 4 is currently Windows-specific, expects Visual Studio 2022 C++ Build Tools and CUDA, and defaults `TORCH_CUDA_ARCH_LIST` to `12.0`.
- Stage 5 exports an empty COLMAP `points3D.txt` because it preserves known camera poses without inventing 3D feature points.
- `npm audit` reports one high-severity advisory group for the locked Vite 8.2.2 development dependency; upgrading to the available 8.3.5 fix requires a separate compatibility review.
